## Entry

> My love language is fixing your typos in real time. My red flag: I keep a spreadsheet of every 'lol' you sent without laughing.

## How it works

`main.py` writes the bio to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (default `out`), as UTF-8 bytes with no trailing newline. Run it with `python3 main.py`.
